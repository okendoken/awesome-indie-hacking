# GitHub 发布检查表

在创建独立仓库后，按以下步骤完成首次发布。

- [ ] 建立公开仓库 `awesome-indie-hacking`，不要在仓库创建页自动添加 README、许可证或 `.gitignore`。
- [ ] 在本目录初始化 Git，并把默认分支命名为 `main`。
- [ ] 将远程地址设置为新仓库的 HTTPS URL。
- [ ] 核对 `PROMO.md` 中的正式仓库 URL；该文件中的社交账号提及只保留已经确认归属的账号。
- [ ] 核对 Idea Miner 的官网链接为 `https://idea-miner.com/`，并确认产品权限和方法说明仍与 README 一致。
- [ ] 检查所有 Markdown 相对链接、Issue 模板和许可证文件。
- [ ] 提交首个版本、推送 `main`，然后在 GitHub 页面检查四份 README 的渲染和语言切换链接。

发布后再补充：仓库简介、主题标签、社交预览图和实际维护者联系渠道。
